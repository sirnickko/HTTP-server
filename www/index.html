🦀 Pure Rust · Zero Dependencies

Rust HTTP Server

A hand-rolled HTTP/1.1 server built from raw TCP sockets — no frameworks, no crates.

⚡

Raw TCP

Every byte parsed manually using std::net::TcpListener. No magic.

🔒

Safe by Default

Path traversal sanitised. ../ escapes are blocked at parse time.

⚙️

Keep-Alive

HTTP/1.1 persistent connections with a 5-second idle timeout per thread.

🗂️

ETag Caching

Automatic ETag + 304 Not Modified support. Saves bandwidth on repeat visits.
